# FLOGORITMA

**A modern, native, and open-source flowchart programming environment.**

Flogoritma helps students learn programming and algorithms by creating, visualizing, and executing flowcharts. Built primarily for Linux, it is designed for everyone.

## Features Planned

* **Visual flowchart editor** — Create and modify flowcharts intuitively.
* **Native Linux application** — Fast, lightweight, and tailored for Linux environments.
* **Step-by-step execution** — Trace your logic closely by stepping through your code.
* **Variable inspector** — Monitor data changes and states in real-time.
* **Input and output** — Handle user data and display results easily.
* **Conditions and loops** — Implement complex control flows seamlessly.
* **Code generation** — Convert your visual logic into written programming languages.
* **Dark mode** — A sleek, modern theme that is easy on the eyes.
* **Import Flowgorithm projects** — Migration and compatibility made simple.
